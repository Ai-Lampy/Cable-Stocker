# Saved Cable Stock Generator projects

Use **Home → Cable stock → Save vendor project** to create a complete cable generator project JSON. Save or move it into this folder using the exact filename shown by the app, then upload it here in GitHub. Rigging backups remain separate.

Selecting that vendor restores its retained local draft first, otherwise loads `projects/<generated-vendor-name>.lampy-project.json`. Use **Load saved vendor project** on Home to explicitly reload the hosted cable project. No project index is required. Keep the vendor name and generated filename consistent. Newly added vendors also need an updated `reference/lighting_vendors.json` to appear in the selector.

These files are for this generator only. Do not put them in Lampy’s cable-stock manifest. Reference edits, including approved connector types, still require their separate reference downloads. Uploaded project files are readable by visitors to the hosted site.

This folder includes your saved **Siyan LTD** project, [siyan_ltd.lampy-project.json](siyan_ltd.lampy-project.json), and **Christie Lites UK** project, [christie_lites_uk.lampy-project.json](christie_lites_uk.lampy-project.json). Keep their exact filenames under `projects/`. Add other saved vendor projects here using their generated filenames.
